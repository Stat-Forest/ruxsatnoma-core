# CLAUDE.md — ruxsatnoma-core

## Что это

`core` — модульный монолит системы «Ruxsatnoma»: выдача электронных разрешений
на пользование землями лесного фонда Республики Узбекистан. Заказчик — Агентство
по лесам. Одиннадцать доменных модулей и три общих, каждый владеет ровно одной
схемой БД. Всё, что ходит во внешние системы, живёт в соседнем сервисе
`ruxsatnoma-integration`; `core` наружу не ходит никогда.

**Сейчас это скелет.** Моделей, миграций и бизнес-логики нет — их пишут владельцы
модулей.

## Стек

Python 3.13 · FastAPI · SQLAlchemy 2.0 + GeoAlchemy2 · PostgreSQL 18 + PostGIS 3.6 ·
Alembic · Pydantic v2 · structlog · aio-pika (RabbitMQ) · Redis. Сборка на pip.

## Команды

```bash
make install    # зависимости в активированный venv
make hooks      # git-хуки
make check      # полный гейт, те же девять шагов, что в CI
make up         # локальная инфраструктура
make api        # API на http://localhost:8000/docs
```

`make check` обязан быть зелёным до открытия PR: он совпадает с CI шаг в шаг,
так что красный CI при зелёном локальном прогоне означает расхождение окружений,
а не каприз CI.

## Правила

### В коде только английский

Имена, комментарии, docstring-и, сообщения коммитов, названия веток и миграций.
Кириллица допустима только в `locales/` и `tests/fixtures/`. Проверяется
`scripts/check_english_only.py`. Пользовательские тексты живут в файлах
локализации и подставляются по ключу.

### Границы пакетов

Пакет = схема БД. Модуль работает только со своей схемой, **даже на чтение**.
Наружу виден только `__init__.py` пакета: ни `models.py`, ни `repository.py`
соседа импортировать нельзя. Проверяется `lint-imports`, контракты — в
`setup.cfg`, обоснование — в `modules.md`.

### Деньги и время

Деньги — `numeric(18,2)` в базе и `Decimal` в коде, никогда `float` и никогда
`int()`: старая система теряла на этом тийины. Время — `timestamptz`, хранение в
UTC, отображение UTC+5. Правило `DTZ` в ruff запрещает наивные даты, `T20`
запрещает `print`.

### Тесты

SQLite не используется нигде — он не умеет ни PostGIS, ни exclusion constraints,
ни RLS, то есть ровно то, на чём держатся инварианты. Интеграционные тесты
поднимают настоящий PostGIS через testcontainers.

### Git

Ветка на задачу плана: `feat/2.8-vmq-689-formulas`. Слияние в `main` только через
PR с зелёным CI; прямой коммит в `main` блокируется хуком. Conventional Commits
на английском. **Никакой AI-атрибуции** — ни `Co-Authored-By`, ни упоминания
инструмента в теле PR. Перед каждым push проверяй, жив ли PR ветки:
`gh pr list --head "$(git branch --show-current)" --state all --json number,state,mergedAt`.

### Уроки

Исправил нетривиальный баг или нашёл неочевидную закономерность — допиши урок в
`.claude/lessons.md`. Формат — в шапке файла. Общие советы по Python туда не
идут, только специфика Ruxsatnoma.
